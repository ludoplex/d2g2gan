dual discriminator · dual generator · one C file

Two generators, one ring, split down the middle.

An adversarial network where the second discriminator asks which generator made this? — so the only way to win is to cover different modes. Every matmul is Fortran sgemm_; LAPACK does the orthogonal init and the metric; the same source links against OpenBLAS or f2c'd netlib and ships as one Actually Portable Executable.

The numbers behind the picture

--hidden 128 --lr 1e-3 --steps 6000, seed 0x9e3779b97f4a7c15, 4 096 samples per generator at evaluation. "hq" is the fraction of samples within 3σ of a mode centre; FD is the 2-Wasserstein distance between Gaussians fitted to real and generated samples (LAPACK ssyev_ for the matrix square root).

L_Dc → 0.000 on both backends is the interesting line: the classifier discriminator can tell the generators apart perfectly, which means they have stopped overlapping.

the model

Why a second discriminator

A single discriminator only asks is this real? — a generator can answer yes forever from one mode. D_c is paid to guess which generator produced a sample, and each generator is paid to make that guess easy. That is only possible when the generators occupy different territory, so mode coverage becomes a term in the loss rather than a hope.

Two 2-layer MLPs with leaky ReLU on each side; Adam with β₁ = 0.5; fakes weighted ½ each in D_r so the real term is not outvoted.

G_k : z(B,8) → lrelu(z·W1_k + b1_k) → x(B,2)      k ∈ {0,1}
D_r : x → logit      real = 1  vs  fake = 0
D_c : x → logit      from G_1 = 1  vs  from G_0 = 0

L_Dr = BCE(D_r(real),1) + ½ Σ_k BCE(D_r(G_k z),0)
L_Dc = ½ Σ_k BCE(D_c(G_k z), k)
L_Gk = BCE(D_r(G_k z),1) + λ·BCE(D_c(G_k z), k)

every matmul, row-major on top of Fortran column-major:
C = op(A)·op(B)   ⇔   Cᵀ = op(B)ᵀ·op(A)ᵀ
sgemm_(&transB, &transA, &N, &M, &K, &alpha, B, &ldb, A, &lda, &beta, C, &ldc);
three disciplines, enforced in the source

Branchless. Arenas. Asserts.

No if inside an elementwise loop

m = (float)(x > 0.0f);
y = x * (m + 0.2f*(1.0f - m));        leaky relu
sig = 0.5f*tanhf(0.5f*x) + 0.5f;      stable σ
sp  = fmaxf(x,0) + log1pf(expf(-fabsf(x)));
k   = rng_u64(r) >> 61;               mode 0..7
ang += 6.2831853f * (float)(ang < 0); wrap

Comparisons become masks, clamps become fmaxf/fabsf, the ring sampler and coverage binning pick modes arithmetically.

Two arenas, one reset per step

Arena persist, frame;
arena_init(&persist, 1<<20);   params + Adam: 62 KB
arena_init(&frame,   1<<20);   activations + grads

ArenaMark fm = arena_mark(&frame);
… forward, backward, Adam …
arena_reset_to(&frame, fm);
ASSERT(frame.total_used == 0);

64-byte aligned bump allocation, chunks double on demand, released back to the mark. Peak 4.95 MB per step at H = 128; zero malloc in the training loop.

cosmopolitan build

Eight things that bit, in the order they bit

OpenBLAS is a dynamic glibc library, useless from a static APE. Netlib CLAPACK 3.2.1 is f2c-translated C and compiles with anything — including cosmocc, once these are handled. All of it lives in the Makefile: make clapack && make cosmo.

d2g2gan.com is 979 KB, starts with MZqFpD, and runs on Linux, macOS, Windows, BSDs, x86-64 and arm64.

  1. Static BLAS — CLAPACK 3.2.1 from netlib, pure C, no Fortran compiler needed.
  2. GCC 14 inside cosmocc hard-errors implicit declarations in 2009-era f2c output: -std=gnu89 -include stdio.h …
  3. libf2c's Makefile hardcodes GNU ar, so no .aarch64/ twin: re-archive with cosmoar.
  4. cosmoranlib ships without +x in cosmocc.zip.
  5. lapacklib runs its INSTALL tests — APE binaries must execute on the build host (binfmt or the sh fallback).
  6. Link archives by path; they are not lib*.a.
  7. blaswrap.h:127 renames sgemm_ → f2c_sgemm; LAPACK keeps the underscore. -DCLAPACK_F2C_WRAP.
  8. typedef long int integer — 8 bytes on LP64 vs OpenBLAS's 32-bit int. One fint typedef, same flag.
